# Security Policy

## Security & Local Data Privacy

Rebyld is a client-side progressive web application (PWA) operating entirely inside the browser.
- All user metrics, workout completion data, and preferences remain stored in `localStorage` and `sessionStorage`.
- No user data or analytics are transmitted to third-party tracking services or external servers.

## Reporting a Vulnerability

If you discover any security issue, DOM vulnerability, or unexpected script execution path in Rebyld:

1. Please email the maintainers with a description of the issue and steps to reproduce.
2. We prioritize client-side DOM security, local storage sanitization, and PWA shell integrity.
